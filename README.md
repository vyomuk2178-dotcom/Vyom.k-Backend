# SpendWise

SpendWise is a full-stack expense tracker designed for teenagers. It provides secure accounts, expense tracking, budgets, savings goals, analytics, and spending suggestions.

## Run locally

```bash
npm install
npm run dev
```

The frontend runs at `http://localhost:5173` and the API at `http://localhost:5000`.

## Project structure

- `frontend/` — React + Vite client
- `backend/` — Express REST API and Supabase integration

## Environment setup

Copy the example environment files and configure the backend's Supabase URL and server-only key. Never commit `.env` files.
